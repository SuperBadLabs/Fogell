## Review and evidence traps learned during this watch

1. A docs-only formal review covers only the changed files. When DONE depends
   on already-merged runtime, request an explicit exact-head whole-boundary
   audit from both Codex and Copilot and preserve their response URLs/IDs.
2. `scripts/review-coverage.py` proves reviewer identity and head coverage; it
   does not clear findings, hosted checks, or unresolved threads. Check all
   three separately.
3. Expecto list filters can match nothing and exit zero. Every focused claim
   needs a positive test count and the expected suite name.
4. A current local gate can verify sealed receipts and a pinned oracle file
   without contacting Jenkins. Say `verified retained evidence`, not `fresh
   live oracle`, unless Jenkins actually ran.
5. Run the authoritative gate in a fresh detached checkout. The canonical
   repository contains a nested `.claude/worktrees` checkout that can pollute
   physical inventory proofs when the root checkout is used directly.
6. Use a dedicated PostgreSQL instance for the exact-head gate and remove only
   that recreatable instance afterward. The unrelated `fogell-fg060a` container
   was observed running and was left untouched.
