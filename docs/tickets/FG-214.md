## Bounded claim

This ticket exposes only the public `duration` property and zero-argument
`getDuration()` on Fogell's nominal
`hudson.tasks.junit.TestResultSummary`. Both return one binary32 value with
boxed `java.lang.Float` provenance (`Number`, never Double or BigDecimal), and
property/getter equality is value-based, including the measured NaN boundary.

The producer follows pinned JUnit plugin `1416.vd753e036de5e`: durations are
seconds; testcase values are parsed and clamped before addition; a present suite
`time` is authoritative even when empty, invalid, negative, NaN, or infinite;
an absent suite time sums direct testcase durations; reached result-owning
suites add child-first in document order and report files add in globally sorted
order. Every addition is binary32. Wrapper-only owner times are ignored,
synthetic empty/malformed cases contribute zero, and permitted empty/no-match
summaries return `0.0f` rather than the unrelated four-count constructor's
`-1f` sentinel.

Generic decimal literals, arithmetic, ordering, ranges, truthiness, iteration,
indexing, hashing, mutation, throwing, direct Float methods, hosted-step
coercion, and mixed numeric equality remain fail-closed. GString rendering is
admitted for the measured ordinary/zero/NaN/infinity Float surface; subnormal
rendering refuses because .NET and the pinned JDK choose different shortest
decimal spellings. Java hexadecimal float tokens likewise preserve counts but
leave duration unavailable instead of using a double-mediated conversion that
can round differently. Oversized uppercase fallback exponents beyond the proven
three-digit DecimalFormat boundary also preserve counts but refuse duration,
because the pinned parser's overflow/parse-stop behavior diverges from ordinary
Double parsing. Those narrower false refusals are explicit residuals, not
guessed values.
