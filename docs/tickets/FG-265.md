# Bounded scripted walker: `node`, `stage` and map-form `parallel` over the hosted interpreter

Priority: **P1**

Verb: **run** a scripted `node { }` Jenkinsfile.

Status: **TODO**. Filed 2026-09-10 by the Track 4 re-cut; the decision is
recorded in `adr/0009`. First Track 4 row by demand.

## Demand

The Scripted row of [FG-263](FG-263.md)'s table, which is the scorer's own
verdict in `corpus/BASELINE-DECLARATIVE-SCORE.tsv` (`scripted-ok` plus
`scripted-err`). FG-245 measured that the walker
refuses every one at 1:1 with `no_pipeline_block`; FG-247's survey counted 122
such files among the admitted rows at its reading. This is the largest single
class in the corpus and it is refused by a `looksDeclarative` regex in
`src/Fogell.Pipeline.Parser/Parser.fs` before anything runs.

## Design

- `Parser.parseWithLimitsAndStagesBodyStart` routes a source with no
  `pipeline { }` block to a new `ScriptedWalker` in the walker project (after
  FG-262) instead of refusing. The whole file becomes one hosted body run by
  `Interpreter.runHosted` with a scripted vocabulary.
- `node` (bare, `node('label')`, `node { }`), `stage('name') { }` and the
  map-form `parallel(a: {...}, b: {...}, failFast: bool)` are hosted wrappers
  added to `WalkerRules.scriptWrappersWithHostedBody`. `node('label')` goes
  through the FG-272 placement seam; until then only the `built-in` label and
  the bare form are admitted. `stage` supplies the journal's stage name;
  steps inside are keyed by `(stage, stepIndex)` exactly as Declarative steps
  are, and top-level steps outside any `stage` refuse (`scripted_step_outside_stage`)
  so the durability key is never ambiguous.
- Everything else scripted — `properties`, `checkout scm` without a defined
  SCM, `currentBuild` before FG-268, `env.X =` before FG-267, classes, `load`,
  `catchError`, `ws`, `lock` — refuses by name before any effect, through the
  FG-264 static pass extended to hosted bodies where a name is statically
  visible.
- The corpus scorer's `scripted-ok` verdict becomes "parses"; the walker's own
  static pass decides "executes", and FG-263's tokens report both.

## Acceptance

One scripted corpus file whose steps are already modelled runs on both engines
under both proven no-egress fences and its receipt is PROVEN tier-1 in the
ledger. FG-242 named `camiloribeiro_cdeasy` (fourteen `sh` bodies, every one a
bare `sleep N`, nine `parallel` calls) as the candidate. Every unmodelled
scripted construct refuses by name before any step effect, proven by a
hand-written case per refusal. Not DONE on the hand-written suite: the
receipt must name a corpus file.

## Jenkins probe first

Measure on luigi: the console shape of `stage` in scripted mode (the
`[Pipeline] { (name)` annotations and whether the receipt canonicaliser
already strips them), map-form `parallel` branch narration and ordering, and
what a step outside any `stage` prints, so the comparison contract is fixed
before the walker is written.
