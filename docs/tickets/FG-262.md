# Split `Fogell.Walker` out of `Fogell.Differential`

Priority: **P1**

Verb: bookkeeping — rides in FG-265's dispatch slot (`adr/0009`, product rule 1).

Status: **TODO**. Filed 2026-09-10 by the Track 4 re-cut (`adr/0009`) as the
first prerequisite: every capability ticket after it edits the walker, and the
walker currently lives inside the project that also holds the Jenkins oracle
client.

## Demand

None directly; this row unlocks no corpus file. It exists because the
2026-09-10 code read found the pipeline execution engine — stage sequencing,
`parallel`, `post`, `when`, wrappers, `script { }` hosting — in
`src/Fogell.Differential/WalkerOrchestration.fs` (about 3,000 lines) with
`Fogell.fs`, `WalkerStep.fs`, `WalkerRules.fs`, `WalkerWhen.fs`, `WalkerGit.fs`,
`WalkerCtx.fs`, `WalkerArgs.fs`, `WalkerCancellation.fs`, `GString.fs` and
`Trace.fs` beside it, while `src/Fogell.Execution/Executor.fs` dispatches only
four leaf arms (`archiveArtifacts`, `junit`, `sh`/`bat`, `echo`/`println`). `Fogell.Controller.Api.fsproj` references `Fogell.Differential`
for one preflight call, so the controller binary links `Jenkins.fs` and
`Compare.fs`, the oracle client and the receipt comparer.

## Design

A pure file move. Create `src/Fogell.Walker/` holding the files named above;
`Fogell.Differential` keeps `Jenkins.fs` and `Compare.fs` and references
`Fogell.Walker`. `Fogell.Controller.Api` and `tools/Fogell.Run.Host` reference
`Fogell.Walker` only. Namespaces stay `Fogell.Differential` for one release so
`audit-stale-refs`, receipts and comments stay inert; a second, separate commit
renames them. No behaviour change is permitted in either commit.

## Acceptance

`tools/Fogell.Differential.Cli --verify-seals` passes over every existing
receipt and `scripts/bin/generate-scorecard --check` reports the ledger
byte-identical before and after the move. The controller binary no longer
links `Fogell.Differential`. The gate is green on the exact head.

## Jenkins probe first

None. Nothing observable changes.
