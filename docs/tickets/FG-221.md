## Implemented scope and evidence level

The two promoted differential receipts prove two bounded behaviors at tier 1.
A self-referential directory link is selected under its logical Ant scanner path
and is pruned after the same canonical directory target has already been followed
five times, so `loop -> .` contributes the base report plus five aliases. A
dangling literal file link takes Ant's no-match path, while the same link selected
by a wildcard becomes one synthetic failed test.

The remaining implemented behaviors are measured separately but are **not
tier-1 claims**. A pinned direct Ant FileSet matrix establishes healthy file,
directory, and external-directory link selection. The focused suite covers those
paths plus final-target zero length and timestamp handling, dangling directories,
file self-loops, pattern pruning, cancellation, traversal/pattern budgets,
permission failures, stable physical-target selection, and unchanged
archive/stash matching. These measurements support the bounded implementation,
but the two promoted receipts do not cover external-workspace traversal,
symlink-target `skipOldReports` timing, or the safety limits.

## Security boundary

Following an external directory link is an explicit compatibility-scanner
exception under ADR 0008. It does not weaken `Workspace.resolveUnder`:
Fogell-managed path arguments continue to reject absolute paths, traversal and
symlink components. The scanner receives only the existing agent account's
filesystem permissions, prunes includes before traversal, applies a fixed work
budget, polls cancellation, and fails closed on authority or I/O errors.

This is an architectural policy decision, not a claim proved by the retained
collector. The collector establishes pinned plugin/Ant behavior and differential
evidence; it does not establish credential isolation, VM containment, or
deployment permissions. Those remain assumptions and requirements of ADR 0008.

## Scope boundary

FG-221 does not claim arbitrary semantics for chains of more than five distinct
link targets, root symlinks, Windows junctions or other platform path behavior,
or hostile multi-tenant isolation inside one agent VM. JUnit object/raw UI,
generic decimal/numeric-width behavior, other wildcard edges, and resumed
timestamp durability remain separate. External-workspace selection and
symlink-target timestamps are implemented and separately measured, but remain
unproven at tier 1 until same-input differential receipts exercise them.
