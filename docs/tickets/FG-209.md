# FG-209 — JUnit testcase children outrank suite aggregate attributes

Status: **DONE** on 2026-08-22.

## Measured divergence

Pinned Jenkins 2.568.1 with JUnit plugin `1416.vd753e036de5e` derives summary
counts from testcase children. With the same named pass, failure, error, and
skipped children, it returns `4,2,1,1` and finishes UNSTABLE whether the suite's
`tests`, `failures`, `errors`, and `skipped` attributes are consistent, missing,
nonnumeric, negative, or numeric but internally inconsistent. All four returned
counts are `java.lang.Integer`.

Before FG-209, Fogell instead read the suite attributes. Missing and nonnumeric
values became zero, negative values survived, and internally inconsistent
values could drive the wrong build result and summary. This was the remaining
aggregate-authority ingest residual identified by FG-177 and narrowed by FG-208.

The read-only oracle matrix also established bounded adjacent rules. Nested
suites recurse. A suite-level direct `<error>` synthesizes one case: error-only
classifies it as failed, while a direct `<skipped>` sibling classifies it as
skipped regardless of element order; skipped-only synthesizes nothing.
`<skipped>` also outranks `<failure>` on the same testcase regardless of element
order, and a zero-result sibling does not discard a valid sibling. Those bounded
adjacent observations remain disclosed as unretained oracle edges; the four core
authority rows below are the retained receipt claims.

## Implementation and retained proof

For exact unnamespaced JUnit elements, each direct testcase child of a recognized
suite contributes exactly once. A testcase with `<skipped>` contributes one skip;
otherwise `<failure>` or `<error>` contributes one failure; otherwise it is a
pass. Suite aggregate count attributes are ignored. The existing malformed and
zero-byte synthetic cases continue to aggregate per file, and I/O and
interruption retain their terminal precedence. Nested-suite traversal uses an
explicit work stack for untrusted depth; focused Execution coverage includes
10,000 nested suites without native stack growth.

Four tier-1 receipts are retained and PROVEN:

- `fg209-junit-missing-aggregate-attrs.receipt.txt`
- `fg209-junit-nonnumeric-aggregate-attrs.receipt.txt`
- `fg209-junit-negative-aggregate-attrs.receipt.txt`
- `fg209-junit-inconsistent-aggregate-attrs.receipt.txt`

Each proves `4,2,1,1,Integer`, continuation, UNSTABLE, ordered output parity,
and exact workspace parity. The immutable completed bundle is
`evidence/20260822T123400Z-fg209-junit-child-authority`.

## Residual boundary

This slice does not claim arbitrary XML or namespace support. Well-formed
reports containing no recognized result remain separate: the pinned oracle
fails an empty suite with no direct testcase, nested-suite result, or direct
suite error with `None of the test reports contained any result`, regardless of
its aggregate attributes. A direct suite `<skipped>` alone also synthesizes no
result and follows that terminal path; a direct suite `<error>` does not. An
arbitrary wrapper with no recognized suite follows the same terminal path. That
zero-result behavior remains an explicit FG-177 ingest residual unless
separately implemented and retained.

JUnit duration, object/UI surface, numeric-width arithmetic, and other options
also remain outside FG-209.
