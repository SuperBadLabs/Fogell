# FG-264 — Agent-facing F# controller client

Status: DONE. Owner: client subagent. Milestone: M1.

Problem: the controller workflow requires hand-built curl orchestration, making
correct idempotency, bounded polling and result interpretation each consumer's job.

Scope: an F# tool exposing submit/status/logs/feedback/watch/cancel with JSON
output. Use current controller endpoints and the FG-263 feedback contract.
Include a concise runbook with exact options, exit codes and examples.

Acceptance:
- Submission requires an explicit idempotency key and prints durable identities.
- Token-file authentication, HTTPS/literal-loopback policy, no redirects, finite
  request/watch timeouts and bounded response reads; diagnostics reveal no token.
- Watch drains pages and returns zero only for authoritative success; failure,
  abort, unstable, reconciliation, malformed/unknown responses and timeout are
  distinguishable from success. Cancellation is explicit.
- Tests use a controllable HTTP handler/server to prove success and rejection
  paths, cursor progress, terminal backlog, and no implicit mutating retry.
- Project is in the solution, has locked dependencies, and tests are discoverable
  by the normal test inventory once files are tracked.

Evidence:
- `tools/Fogell.Client` implements all six commands and is wired into `Fogell.slnx`.
- `tests/Fogell.Client.Tests` is an Expecto executable with locked dependencies.
  `dotnet run --project tests/Fogell.Client.Tests/Fogell.Client.Tests.fsproj -c Release --no-restore -- --summary`
  passed 17/17 on 2026-09-22. Cases cover terminal backlog, all terminal outcomes,
  unknown/corrupt identity/schema/cursors, resume/truncation, byte limits with and
  without Content-Length, credential sanitization, named API refusals, no
  mutating retries, explicit keys, URL refusal, redirects, watch/request deadlines,
  positive cancellation acknowledgment, bounded token normalization, and Linux
  FIFO refusal for both token and pipeline inputs.
- Operational usage and precise exit semantics: [runbook](../runbooks/feedback-client.md).
- Restore succeeded from available dependency cache; NuGet vulnerability metadata
  was unavailable in the restricted network environment (NU1900 warning).
- Live controller campaign and combined gate evidence are tracked in FG-265.
  M1 remains an internal experiment; this client does not establish production
  readiness, verified source identity, or structured test diagnosis.
