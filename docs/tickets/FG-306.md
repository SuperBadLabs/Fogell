# FG-306 — Qualify representative output

**Wave:** W2 · **Priority:** P1 · **State:** Blocked on FG-311 · **Depends on:** FG-305 (done)

Run Fogell's full build/test and a named noisy workload through the native
controller. Check output pagination, terminal status, exact artifacts, and
resource use using the same source-bound candidate as FG-305.

The named noisy workload is Apache Maven's `api/maven-api-annotations`
reactor test in debug output mode. Its snapshot must include the root, API
parent, and module source. Record the exact Maven repository commit and tool
version. Fogell's full locked build/test is the other workload. Use explicit
source snapshots, not a mutable checkout inside the worker.

**Done when:** both workloads complete with no missing, duplicate, or reordered
records; raw output and measurements are retained; failures are reported rather
than hidden. Name the noisy workload before the run.

Fogell's controller-run gate is currently blocked by [FG-311](FG-311.md).
The standalone gate remains green; the nested controller attempts and their
failure feedback are part of W2 evidence, not a waiver of this ticket's exit
criteria.

debug-output lifecycle through the controller. Its 188,271-byte artifact
matched 2,517 ordered feedback records over 26 pages. The module has no test
