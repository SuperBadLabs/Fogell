## What this proves and does not

This proves the Declarative walk through `agent any`, the first stage and a
one-line `sh`; the exact Make executable and diagnostic; failure propagation;
empty-workspace identity; and ordered skipping of both later stages. It does not
prove any intended Make target, Docker build, `ls`, or JUnit behavior because
none is reached. It does not turn an operator-built oracle derivative into a
general package-distribution claim.

The image and tool identities make this receipt reproducible on the current
lab. The image seeds the runtime-pinned 154-plugin closure into a fresh
anonymous home on each run. Zero inherited jobs, empty queue, idle online node,
core, plugin closure, image, tool and port are checked before execution; the
full container ID and home volume are proven absent before access fences lift.
A separately published supply-chain-attested oracle image remains outside this
compatibility slice.

The receipt seal itself binds the case digest, results, compared output, and
workspace hashes; it does not encode tool identities. The signed source commit
binds that seal to the allowlist's structured pin and the fail-closed lane which
checks it. The publication record below binds both exact identities.
