## Implemented contract

Local and remote collection now model regular files plus physical empty leaf directories. Directory symlinks are not followed, and a symlink to an empty directory is not emitted as an empty directory. Non-empty directories are represented by their descendants rather than by separate directory rows.

The remote wire grammar is deliberately strict and versioned:

```text
FOGELL-WORKSPACE-MANIFEST<TAB>2<LF>
F<TAB><64 lowercase hex><TAB><canonical base64 UTF-8 path><LF>
D<TAB><canonical base64 UTF-8 path><LF>
END<TAB><decimal record count><LF>
```

Decoded paths must be canonical relative slash paths, and records must be strictly ordered by UTF-8 path bytes. The parser refuses unknown versions or tags, malformed/noncanonical encoding and paths, duplicate or file/directory-conflicting paths, out-of-order rows, count or framing errors, nonzero collector status, and impossible leaf hierarchies. The hierarchy check considers every observed slash-boundary ancestor, so an interposed lexical row cannot hide an ancestor/descendant contradiction; lexical prefixes such as `a` and `ab` remain distinct.

Canonical file records retain their established v1 `<path><TAB><hash>` bytes and deterministic order. An empty leaf adds a reserved NUL-tagged `D` record with a canonical base64 path. The version header, trailer and count validate transport completeness but are intentionally not part of the workspace hash.
