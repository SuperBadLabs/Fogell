# FG-312 — Prepare the seven-day native pilot

**Wave:** W4 · **Priority:** P1 · **State:** Ready · **Depends on:** FG-310

Deploy the qualified single-host native candidate to the named Luigi staging
host, with separate state and PostgreSQL database from any existing pilot.
Pin the Fogell, Apache Maven, and clenkins source revisions and their native
pipeline definitions. Record the submission, first-feedback, terminal,
artifact, disk, and database measurements for every run, including failures.
Exercise cold dependencies before counting an idle-host latency sample.

**Done when:** a reviewed pilot manifest names all three exact source revisions,
definitions, host resources, operator contact, evidence location, and a
repeatable measurement procedure. A control run for each repository reaches
a terminal result with retrievable artifacts and feedback. Record deviations
before starting the seven-day clock.
