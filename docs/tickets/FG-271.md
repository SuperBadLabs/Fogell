# Executors greater than one, and `disableConcurrentBuilds` made live

Priority: **P1**

Verb: **run** two builds at once.

Status: **TODO**. Filed 2026-09-10 by the Track 4 re-cut (`adr/0009`).
Prerequisite for FG-272 and FG-275.

## Demand

No corpus file names an executor count, so this row takes no rank from
demand; it is here because FG-275 (`build job:`) cannot exist with one
executor and FG-272's labels are meaningless without more than one slot. The
2026-09-10 code read found concurrency is exactly one by control flow, not by
a setting: `LocalWorker` (`src/Fogell.Controller.Host/Worker.fs`) awaits
`runClaim` inline inside the organisation scan.

## Design

- `ControllerConfig` gains `FOGELL_WORKER_EXECUTORS` (1..64, default 1 so
  nothing changes until an operator asks).
- The claim loop becomes: claim while `running.Count < executors`, track each
  `runClaim` task, keep one lease owner (the fence is per attempt, so a shared
  owner is correct), and continue the organisation round-robin between claims.
  Workspace collision is already impossible: the workspace key is the build
  key.
- `disableConcurrentBuilds` is `InertForSingleBuild` today
  (`Fogell.fs`, the option descriptor table). With executors greater than one
  it becomes live: `ClaimNextExecution` (`Store.fs`) gains a project-level
  serialisation predicate — do not offer an attempt whose project has a
  non-terminal attempt when the definition declares the option. The option's
  descriptor moves from inert to honoured.

## Acceptance

Two builds of different projects run concurrently under one controller with
`FOGELL_WORKER_EXECUTORS=2`, each reaching terminal with the same journal and
result as when run alone (hand-written lane, both orders). Two builds of one
project declaring `disableConcurrentBuilds()` run serially, and `ExplainWait`
names the reason. A crash-lane case proves that a worker SIGKILL with two
running attempts requeues both by lease expiry with fences preserved.

## Jenkins probe first

None; nothing here is observable in a single build's console. Note
`EXECUTOR_NUMBER` becomes the slot index, and check the receipt canonicaliser
already treats it as a run-scoped token.
