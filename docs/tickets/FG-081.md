# FG-081 — migration and rollback rehearsal

Status: **DONE locally; publication remains owner-controlled**.

Fogell now has an executable restore-based rollback contract for its newest
PostgreSQL migration. `scripts/migration-rollback-drill.sh` constructs the full
N−1 state, applies N, restores N−1 from a hash-bound custom archive, and applies N
again. Each of the four observed phases—pre, first forward, rollback, and second
forward—is rebuilt in a separate clean database so PostgreSQL must re-create and
validate every foreign key from the stored rows.

The fixture covers organizations, projects, builds, nodes, three attempt states,
events, outbox, logs, an authority-valid effect checkpoint, a canonical retry
child, the retry decision trigger's publications, migration ledger rows, and
sequence state. This is deliberately more than an empty-schema migration test.

The logical digest combines canonical clean-room schema, sorted business-table
rows, exact migration version/checksum ledger, and sequence configuration/state.
The rollback digest must equal pre-upgrade; second-forward must equal first-
forward. The rollback archive is SHA-256 checked both before and immediately
before use.

The hostile proof runs a positive live rehearsal, requires four candidate
faults to refuse, and kills four byte-changing mutants. The covered false-green
paths are archive tampering after hashing, restored data drift, missing latest-
migration FK, skipped second forward, removal of each principal hash comparison,
and an overbroad database namespace.

The CI workflow runs the proof and standalone drill against its PostgreSQL 16
service using server-matched client tools. The operator procedure and explicit
non-goals are in `docs/runbooks/migration-rollback.md`.

Local HeMan development result for migrations `0004 → 0005 → 0004 → 0005`:

- rollback canonical hash equalled the pre-upgrade hash;
- second-forward canonical hash equalled first-forward;
- all four clean-room FK rebuilds succeeded;
- all four planted candidate faults refused;
- all four byte-changing mutants were killed;
- every generated `fogell_fg081_*` database was removed.
