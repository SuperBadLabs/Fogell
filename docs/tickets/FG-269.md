# Shared libraries from a pinned git ref, `vars/` only

Priority: **P1**

Verb: **load** a shared library.

Status: **TODO**. Filed 2026-09-10 by the Track 4 re-cut; the decision to load
rather than refuse is recorded in `adr/0009`. Depends on FG-264 (which makes
the reference visible) and on the interpreter's closed vocabulary.

## Demand

The `@Library`, `library` step and `buildPlugin(` rows of [FG-263](FG-263.md)'s
table. Almost every `@Library` file is scripted (see the table's Declarative
column), so before FG-265 lands this ticket unlocks little on its own. The
`buildPlugin` files are named here as NOT unlocked by this ticket:
`buildPlugin` needs classes and map iteration the interpreter does not have.

## Design

- Operator configuration `FOGELL_LIBRARY_SOURCES`: a list of
  `name=<git-url>@<sha>` entries; only an exact sha is accepted (no branch
  names), and under the no-egress fence the URL must be loopback.
- `@Library('name@sha') _` and `library 'name@sha'` resolve to a configured
  entry; a mismatch in name or sha refuses `unsupported_shared_library`
  naming both. Implicit libraries (configured `implicit=true`) load for every
  build.
- Only `vars/*.groovy` is loaded. Each file's `call` body enters the
  interpreter through the `preambleFuncs` seam in `WalkerOrchestration.fs`
  (functions folded into `Env.withFunc`), with the same closed step vocabulary
  and sandbox as `script { }`. A `vars/` file defining anything other than
  `call` and helper `def`s refuses; any `src/` tree refuses
  `unsupported_library_class`.
- The library checkout is digest-recorded in the journal (`LibraryDigest`) so a
  resume against a different library refuses by name.
- Harness: `Jenkins.fs` configures the identical library as a Global Pipeline
  Library at the identical sha in the pinned Jenkins, from the same loopback
  repository, and the receipt's comparison contract names it.

## Acceptance

A tier-1 receipt for a corpus file whose `@Library` or `library` step resolves
to a `vars/` function the interpreter can run, with the library served from a
loopback repository on both engines. A hand-written case proving an `src/`
class refuses by name, and one proving a sha mismatch refuses by name.

## Jenkins probe first

Measure on luigi: the console lines Jenkins prints when loading a library
(`Loading library name@sha`, the checkout narration) so the canonicaliser is
extended before comparison; whether a `vars/` `call` sees the caller's `env`;
and what an unresolvable library prints.
