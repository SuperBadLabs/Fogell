## Narrow runtime-guard admission

The runtime guard continues to reject arbitrary preambles and environment
blocks. Its new absence-only arm is bound to the measured source shape and
requires all of the following:

- the first user stage is the existing unconditional, inherited-agent shape;
- its first shell is a closed literal invocation of the absent pinned command;
- the preamble AST is exactly the zero-argument `getdockertag()` helper;
- the pipeline environment is exactly the constant `DOCKER_REGISTRY` followed
  by the FG-260-preflighted `DOCKER_TAG = getdockertag()` expression;

- the first stage has no environment block; and
- later, unreachable stage environment values are constants, not expressions.

The target-side PATH, build-token, command-absence and nonce-marker checks remain
injected before the first user stage. Hostile controls reject extra preamble

pipeline GStrings, extra process-control bindings, Unicode escapes in strings
and comments, first-stage environment, and later-stage expressions. The
runtime-pin proof kills mutations of each new guard predicate.
