# FG-302 — Reject invalid environment names

**Wave:** W1 · **Priority:** P0 · **State:** Done

The parser's `$` regex anchor accepts a final newline before the end of an
environment name. Enforce the documented ASCII rule for both pipeline and step
`env`: `[A-Za-z_][A-Za-z0-9_]*`, with no trailing LF, CRLF, or other control
character. Keep duplicate-name and reserved `FOGELL_` refusals intact.

**Evidence:** commit `9550bb05` covers valid boundaries and invalid trailing
LF/CRLF at both scopes. The parser suite passed 28/28. The real runner refused
the September 26 reproducer before workspace or journal creation, and the
controller returned HTTP 422 for root LF and step CRLF names. FG-304 passed
the full matrix and gate on this exact candidate.
