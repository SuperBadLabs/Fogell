# FG-313 — Execute failure and interruption pairs

**Wave:** W4 · **Priority:** P1 · **State:** Ready · **Depends on:** FG-312

Run at least ten deliberate failure/fix pairs across the named pilot repos,
plus a burst-output case, controller restart, and worker interruption. Keep
the failed and fixed attempts, source identities, feedback, artifacts, and
operator actions together. Stop on false success, lost evidence, or an
unobserved replay and open a release blocker immediately.

**Done when:** all ten pairs have explicit failed and fixed terminal outcomes;
interrupted work is terminal or marked reconciliation-required; no uncertain
external effect is replayed automatically. Include raw requests, feedback,
artifacts, and a concise outcome ledger in the pilot report.
