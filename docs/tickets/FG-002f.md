# FG-002f — Audit every `isDiagnosticLine` pattern for user-reproducibility

**Status:** **DONE**  ·  **Priority:** P1

Archived from the execution board on 2026-08-02. The board carries the
outcome; this file carries the reasoning, which is what a future reader
needs and what a planning table cannot hold.

---

The SAME defect has now been found three times: `Terminated` matched unconditionally, then the changelog warning by prefix, then a Groovy compile report by prefix — and the third was added *while fixing* the second. The shape is always identical: a pattern a user's own output can match gets suppressed from the compared output AND counted as a reported failure reason, so one engine failing silently can still read PROVEN. Remaining moderate-risk patterns to adjudicate: `FATAL:`, `Failed in branch `, `Aborted by `, `^at …(…)$`, `No artifacts found`, `\d+ of \d+ test(s) failed`. **Discharged empirically, by deleting each candidate and re-running all 49 receipts.** Result: **six of the suppressions were DEAD** — `FATAL:`, `No artifacts found`, `N of M test(s) failed`, `Aborted by `, the compile-report trio, and the skipped-stage regex — every one a latent false-PROVEN path protecting nothing. Two were load-bearing and are now handled without a user-reproducible match: Fogell **emits** `Failed in branch <name>` as Jenkins does (so neither copy needs suppressing), and Java stack frames are **context-gated** to the window opened by an exception line. The finding underneath: my instinct on a divergence was to add an exclusion rather than check whether the engines already agree — six times out of eight, they did. The three exception-class prefixes that survived that pass were themselves flagged next round (the **fifth** instance) and are now context-gated: an exception head is narration only when a frame FOLLOWS it. `tests/Fogell.Differential.Tests` is the acceptance the ticket asked for — it emits every look-alike from a build and asserts it survives, and it names the one residual ambiguity (a build printing an exception head then a frame is byte-identical to a real trace) rather than pretending the gate is total
