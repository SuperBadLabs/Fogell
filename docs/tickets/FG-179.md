# FG-179

## The by-value capture fix is UNPROVEN BY RECEIPT, deliberately

PR #54 review found that dropping `VClosure`'s stored `Env` had become a REGRESSION once
locals were cells: a closure passed by value wrote to a same-named caller local instead of
the variable it captured. Fixed by carrying the stored environment through the wrapper
normalisation, and verified by host probe — the body writes the captured value and the
caller's variable is untouched.

There is no differential receipt for it, and there cannot be one yet. Every spelling
Jenkins accepts requires invoking a closure held in a local, which is denied here
(FG-189); the one spelling Fogell can run — a `def` method declared inside `script { }` —
Jenkins rejects outright. The case was written, measured against both engines, and
DELETED rather than left in the suite unproven.
