# FG-179

**Current behaviour is in the receipts, not here.** This file states what is OPEN and why
the ticket exists. It deliberately contains no account of what works today, because that is
what kept going stale.

## Open

Dated where a measurement exists, because a measurement is a fact about a run rather than a
standing claim. The heading used to say every row was measured; the one row left is not, and
saying so in a table while claiming otherwise above it is the drift this file exists to avoid. **This list is what
has been probed — it is neither a proof that nothing else survives, nor a guarantee that
every entry still does.** Both directions have been wrong here: it once omitted a defect
recorded elsewhere in this same file, and it once retained one that had been fixed two
commits earlier.

own — but likely is not measured, and this ticket has already been wrong twice by
reasoning from mechanism instead of running it.

## Why it is one ticket and not five patches

`EnvUserShadowed` is a single interpreter-wide bit, set when the interpreter happens to
notice `def env` or `env = …`. It has now been wrong for five distinct spellings — a
wrapper-local `def env`, a local `env` map, a closure-local `def env`, a captured wrapper
environment, and a parameter. Every fix was a guard keyed to how the binding was SPELLED,
and the next spelling was always outside it.

A name's provenance belongs to the FRAME that bound it. That is the work this ticket
carries, and it is why a sixth guard is the wrong answer even when it would close a real
defect.

## Fixed but unproven by receipt

The by-value capture regression (a closure passed as a value ran against the call site's
scope, and once locals became ref cells that became a wrong WRITE) is fixed and verified by
host probe. A differential receipt was impossible when this was written — every spelling
Jenkins accepts needed a closure held in a local to be invocable, which was FG-189 — and
the case written then was measured and deleted rather than left unproven. **FG-195 landed
2026-08-17 and retired that limit**: closures invoke in both spellings, and the parameter
shape this ticket carried as unmeasurable is now receipt-proven matching
(`script-closure-param-named-env`). The ticket closes with nine receipted fixes and the
tenth shape measured.
