## Closed bounded shapes

This tranche closes the false positives labelled (b), (c), (e), (f) and (g) on
the execution board:

- `true`, `false` and `null` in a pattern are literals, not binders; neighboring
  real tuple binders remain collected.
- Active-pattern and parenthesised-operator definition headers are distinguished
  from destructuring patterns, so their following parameters are not invented as
  top-level tuple binders. Conventional and numeric-neighbor tuple controls keep
  the supported extraction live.
- One or more leading underscores remain part of the identifier. The four-byte
  eligibility floor applies to the complete captured token, not only its suffix.
- Removed F# lines are projected from the full base blob with lexical state
  carried across lines. Text wholly inside block comments or carried strings is
  not treated as removed code, while code after a closing delimiter remains
  visible.
- Destructured-token matching has a real left boundary, so a constructor such as
  `Choice` cannot be entered at its second character to invent `hoice`.

The proof uses exact clean/reported diagnostics and ten direct source mutations.
The mutations separately make literal filtering, definition-header exclusion,
underscore retention, full-base lexical projection and constructor boundaries
load-bearing rather than relying on the unchanged repository to exercise them.

## Open misses and scope boundary

Two false-negative shapes are deliberately not claimed closed:

1. **(a)** The surviving-definition arm can still cross quoted literal text, so
   a string containing a deleted identifier can make that identifier appear to
   survive.
2. **(d)** That arm still lacks an explicit left boundary for the searched
   identifier, so a longer surviving binder can hide a deleted suffix binder.

The audit remains a bounded lexical checker for supported top-level F# binding
shapes, not a complete F# lexer or pattern parser. Closing false positives does
not establish that every possible stale-reference miss is detected. Those
limits, plus unpublished integration, keep FG-117 PARTIAL.
