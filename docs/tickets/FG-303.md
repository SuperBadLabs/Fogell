# FG-303 — Persist failed JUnit results

**Wave:** W1 · **Priority:** P0 · **State:** Done

failure-only `StepReason` to the journal. The persisted runner and real controller
proofs verify later steps, artifact publication, and terminal `unstable` status.

**Evidence:** `b5d77a1e` contains the fix and regressions. The native gate passed
569 tests with a zero-warning build on September 27, and the updated controller
proof passed separately after its JUnit assertion was added.
