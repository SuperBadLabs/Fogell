# FG-252 — A `${…}` placeholder inside a Declarative GString is decoded as outer text, so a backslash in placeholder code is the wrong value or a refusal

Status: **TODO** (P3). Filed 2026-09-04 (committer's local clock) from Codex's
review of FG-248's PR #412; measured on both engines before filing, not
implemented. The scripted parser keeps placeholders as expressions (`GExpr`)
and does not have this defect.

## Measured, 2026-09-04

`echo "R: ${/\s/} and ${1 + 1}"` as a Declarative step:

| engine | result |
|---|---|
| Jenkins 2.568.1 (one transient job, deleted) | `R: \s and 2` — the slashy literal inside the placeholder keeps its backslash |
| Fogell at `origin/main` `43b12d16` (before FG-248) | `R: s and 2` — `\s` decoded to `s` as if it were outer text, so a different regex was evaluated, silently (class A) |
| Fogell at the FG-248 head `b6cdbd90` | refused: `invalid Groovy escape \s` at the placeholder (class B, loud) |

Cause, read in `src/Fogell.Pipeline.Parser/Lexeme.fs` and `Parser.fs`: the
Declarative GString consumers (`quotedKeepingDollar`,
`tripleQuotedKeepingDollar`) and the raw-argument scanner's quoted-literal
loop are flat scans that run every backslash through the outer literal's
escape rule, including backslashes inside `${…}` — where Groovy is lexing
CODE (slashy literals, nested strings, comments), not the literal's text.
The same flat scan means `${'a\nb'}` hands the interpreter a placeholder
holding a physical newline. Corpus: zero `${…}` placeholders contain a
backslash (regex over 228 files), which is why this is ranked P3 despite
the class-A history.

## What would close it

The three scanners recognise `${` and copy the placeholder verbatim to its
balanced `}` (skipping nested quoted, triple-quoted and slashy literals and
comments), leaving decoding to the interpreter that evaluates the
expression; a Jenkins measurement per nested form first; a case whose
placeholder holds a slashy literal with a backslash and a nested quoted
string with an escape; FG-248's refusal then applies only to the literal's
own text, and this row's refusal shape disappears.
