# FG-195

**Current behaviour is in the receipts and in the four refusals named below.** This file is
the specification, written while the four defects were fresh.

## The one sentence

Resolution is by **name**. Groovy's is by **signature**. Every defect below is a call
landing on something the language would not pick.

## The four, each measured before being refused

| | shape | Groovy | Fogell before the refusal |
|---|---|---|---|
| a | `def x = { 'LOCAL' }` then `x()`, with a preamble `def x()` | the local | ran the **helper** |
| b | `def pick()` beside `def pick(v)`, called `pick()` | the zero-arg body | ran the **one-arg** body (map by name, last wins) |
| c | `def constant(v)` called as `constant()` | rejected — no zero-arg overload | bound nothing, **ran the body** |
| d | `def zero()` called as `zero(foo: 1)` | rejected — named args are one Map argument | counted zero positionals, **ran the body** |

All four reported SUCCESS. (d) was found *inside the guard written for (c)*, which is the
sharpest evidence that counting is not resolving.

## Where the code decides today

Verified by touching each during FG-188, not inferred:

- `Sandbox.admitCall` admits by NAME against `RegisteredSteps` and `Defined`.
- `Interpreter.runWith` builds `Defined` from the script body **and** `env.Funcs` names.
- The `Ok(Builtin b)` branch looks up `env.Funcs` by name and executes the body.
- `WalkerOrchestration`'s script arm supplies preamble helpers as `env.Funcs`.

The four refusals live at the last two points. Each promises "unsupported" about ordinary
Groovy that Jenkins runs, so they are debt with a known interest rate.

## What replaces them

1. A callable is a **name plus a signature** — parameter count, and eventually names for
   the named-argument form. `env.Funcs` becomes a map from name to a LIST of candidates.
2. **Resolution picks by arity** among candidates, counting Groovy's argument forms: a
   named-argument group is ONE Map argument, and a trailing closure is a final argument.
   That rule is already written down in the builtin path — reuse it rather than restate it.
3. **A local binding shadows a helper.** Resolution consults `env.Vars` before `env.Funcs`.
4. **A closure value is callable** — this is FG-189, and it folds in here rather than
   standing alone, because (3) is only correct once a shadowing local can actually be
   invoked.
5. **No match is a refusal with the attempted signature named**, not a silent nearest fit.

## The trap this ticket must not repeat

Three of the four refusals were added one at a time, each after the previous one shipped,
and each looked complete when written. A signature model is only a fix if it is checked
against ALL FOUR shapes at once — the fourth exists because a guard was written while
looking at one of the three ways Groovy forms an argument.
