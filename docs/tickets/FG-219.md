# FG-219 — JUnit trailing-directory include shorthand

## Claim

Pinned Jenkins 2.568.1 / JUnit `1416.vd753e036de5e` / Ant 1.10.17 treats a
scanner-relative JUnit directory prefix ending in a separator as recursive
directory shorthand.
`outer/reports/` and `outer/reports//` select the same direct and nested files as
`outer/reports/**`. Base Fogell compiled the trailing slash literally and matched
no enumerated file.

FG-219 keeps FG-218's JUnit-private separator normalization and models Ant's
appended terminal `**` with a descendant arm plus, for wildcard-bearing prefixes,
a suffix-free arm for `**` consuming zero path components. Wholly literal file
prefixes do not receive that arm.
Case sensitivity and default excludes remain in force; the public archive/stash
matcher is unchanged.
